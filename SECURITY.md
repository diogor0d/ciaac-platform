# Segurança

## Comunicar uma vulnerabilidade

Não publiques detalhes exploráveis, credenciais, dados de jogadores ou
informação de infraestrutura num issue público. Usa a funcionalidade privada
«Report a vulnerability» do separador Security deste repositório.

Inclui a versão afetada, impacto, pré-condições e passos mínimos de reprodução
com dados sintéticos. Não testes contra servidores ou contas reais sem
autorização explícita.

## Âmbito

São relevantes vulnerabilidades no artefacto CIAACPlatform, atualizador,
assinatura de versões, isolamento de inventário/progresso, autenticação,
permissões, recuperação e integridade económica. A publicação de uma correção
não constitui prova de implantação ou validação em produção.

Segredos, dados pessoais, bases de dados, mundos e registos de produção não
pertencem a este repositório. Se encontrares algum destes materiais, não os
copies nem os redistribuas; comunica o caso pelo canal privado.
